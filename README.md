# NPL Giveaway

Signup, match predictions, points and leaderboard for the NPL Season 3 giveaway by LekhaSetu. Players sign up with name, email and phone, predict match winners and margins, and the highest points total after the final wins Rs. 1,000. Works with the NPL Giveaway theme.

- **Version:** 1.0.3
- **Author:** Nirmal Kumar Bhattarai
- **License:** MIT

## Install

1. Download or clone this repository.
2. Copy the folder into `wp-content/plugins/` on your WordPress site.
3. Activate it in WordPress admin (Plugins).
